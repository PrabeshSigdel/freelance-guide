# AATF Expedition Base Theme

## Purpose
This theme is the branding/layout layer for the `aa-trek-framework` plugin.

- Plugin = data model + business framework
- Theme = visual identity + page layout

## Required Plugin
Activate `AA Trek Framework` before using this theme for full output.

## Quick Setup
1. Activate `AA Trek Framework` plugin.
2. Activate `AATF Expedition Base` theme.
3. Go to `Settings -> Permalinks` and click Save.
4. Go to `Trek Framework -> Design System` and set brand colors.
5. Add Treks and related data.

## Templates Included
- `front-page.php`
- `archive-trek.php`
- `single-trek.php`
- `page.php`
- `index.php`

## Reusable Rule
For each client project:
- Keep plugin same (core framework)
- Clone this theme and adjust only branding/layout
